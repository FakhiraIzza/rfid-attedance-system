# RFID-Based Student Attendance System

An Internet of Things-based student attendance system developed using
NodeMCU ESP8266, MFRC522 RFID, PHP, MySQL, and WhatsApp notification integration.

## Main Features

- RFID-based check-in and check-out
- Role-based dashboard for administrators, teachers, and parents
- Real-time attendance monitoring
- Automatic attendance status processing
- Offline data queue using LittleFS
- WhatsApp attendance notifications
- CSV and PDF attendance reports

## Technologies

### Hardware
- NodeMCU ESP8266
- MFRC522 RFID Reader
- LCD 16x2 I2C
- Passive buzzer
- MIFARE RFID Card

### Software
- PHP
- MySQL
- HTML, CSS, JavaScript
- REST API
- Arduino IDE
- LittleFS

## Project Structure

- `public_html/`: Web application and REST API
- `firmware/`: ESP8266 firmware
- `database/`: Database structure
- `docs/`: Diagrams and screenshots

## Security Notice

Credentials, Wi-Fi passwords, API keys, and real student information are not
included in this repository.
